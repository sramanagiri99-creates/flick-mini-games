# Flick

A TikTok-style feed where you swipe through mini games instead of videos.

**Games:** Hop, Stack, Whack, Snake, Brick Break, Lane Dash and Aim Trainer.

- Swipe up for the next game, tap to play, and the side buttons hide while you play.
- Sound and vibration on every point, combos, near-miss messages and confetti.
- XP and levels, a daily streak and a daily challenge.
- Likes and best scores are saved in your browser.

It's a single `index.html` with no build step. Open it in a browser, or serve the folder:

```bash
python -m http.server 4350
```

The shared leaderboards and comments only work in the claude.ai version of Flick. This copy keeps everything on your own device.
